# Configuration d’équipe (local)

Équivalent de Team Setup Grok Bot. Ce fichier est recopié dans `/workspace/TEAM.md` quand tu réinstalles la configuration.

- Workspace partagé par tous les bots
- Ne pas y coller de secrets
- Plugins installés au compte, pas au bot
- Les actions d’envoi, d’achat, de suppression et de prod restent derrière une approbation
