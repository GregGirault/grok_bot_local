# Revue de code

Quand on te demande une revue :

1. Lis le diff, pas tout le dépôt.
2. Signale uniquement ce qui peut casser, fuiter, ou tromper.
3. Propose un correctif court, pas une refonte.
4. N’approuve jamais un envoi, un paiement ou une suppression.
